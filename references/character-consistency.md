# xuanmu Character Consistency

This file is the source of truth for keeping Xuanmu visually consistent across all generated illustrations.

Every generated image must follow this file together with:

- `references/xuanmu-ip.md`
- `references/style-dna.md`
- `assets/character-sheet/character-sheet.png` if available

---

## 1. Character Name

Character name:

- 玄木
- Xuanmu

Do not call the character:

- Xiaohei
- 小黑
- Yuan Builder
- mascot
- black blob

---

## 2. Fixed Visual Identity

Xuanmu must always keep the same recognizable identity.

### Hair

- short black hair
- slightly fluffy
- clean hand-drawn silhouette
- no long hair
- no strange color hair
- no exaggerated anime hairstyle

### Face

- Q-version face
- large eyes
- simple facial features
- restrained expression
- not overly cute
- not meme-like
- not childish

### Body Ratio

- Q-version proportion
- head-to-body ratio around 1:2.5 to 1:3
- compact body
- clear action pose

### Outfit

Fixed outfit:

- Klein blue hoodie
- Naples yellow details on hood string, collar, cuffs, or small badge
- black workwear pants
- black and yellow sneakers

Do not change the core outfit.

Allowed additions:

- tool belt
- gloves
- small controller
- blueprint folder
- engineering pen
- headset
- small backpack

These additions must not replace the fixed outfit.

---

## 3. Fixed Color Palette

### Primary Color

Klein Blue

- hoodie
- control devices
- important system structures

Naples Yellow

`#FADA5E`

Use for:

- hoodie details
- buttons

- highlights
- energy points

Use for:

- outlines
- pants
- text
- mechanical details

### Background

White or warm white:

- `#FFFFFF`
- `#F7F7F5`

---

## 4. Allowed Pose Changes

Xuanmu can change pose according to the task.

Allowed actions:

- operating a console
- adjusting a lever
- sorting cards
- carrying a small module
- connecting cables
- inspecting signals
- building a structure
- tuning a reactor
- drawing on a blueprint
- pushing a module
- standing on a platform while working

Not allowed:

- standing still as decoration
- waving without function
- posing for a poster
- sitting without doing anything
- appearing only as a sticker

---

## 5. Expression Rules

Xuanmu should look calm, focused, rational, and engaged.

Avoid:

- exaggerated laughter
- exaggerated crying
- meme expression
- childish cuteness
- angry comic expression
- horror expression

---

## 6. Style Consistency

Every Xuanmu illustration must feel like it belongs to the same visual system.

Required:

- hand-drawn editorial style
- blue-yellow-black palette
- clean white background
- system / engineering metaphor
- knowledge builder feeling
- controlled text labels
- enough negative space

Avoid:

- 3D render
- oil painting
- cyberpunk
- heavy gradient
- anime poster
- children book style
- random cartoon mascot style

---

## 7. Character Sheet Priority

If `assets/character-sheet/character-sheet.png` exists, it is the highest visual reference for Xuanmu.

Use it as the source of truth for:

- hairstyle
- face shape
- body proportion
- outfit
- color distribution
- shoes
- general silhouette

Do not copy the pose from the character sheet unless the task requires it.

Use the character sheet for identity, not composition.

---

## 8. QA Rules

Reject the image if:

- Xuanmu does not look like the same character
- outfit changes too much
- hair changes too much
- color identity is lost
- Xuanmu becomes Xiaohei-like
- Xuanmu becomes a generic cartoon person
- Xuanmu appears only as decoration
- the visual style no longer matches xuanmu

Accept the image only if:

- Xuanmu is recognizable at first glance
- outfit remains consistent
- palette remains blue-yellow-black
- Xuanmu performs the core action
- the image still supports the original cognitive logic

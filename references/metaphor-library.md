# xuanmu Metaphor Library

This library defines the preferred metaphor system for xuanmu.

Core visual world: control rooms, signal towers, knowledge reactors, modular factories, observatories, system-bearing devices, orbit systems, evidence structures, content laboratories, decision engines, knowledge vaults, working consoles, mechanical diagrams, hand-drawn engineering devices.

---

## Concept Mapping

### 判断

Use Decision Engine, Control Console, Signal Sorting Machine, Routing Station, Multi-lever Operating Desk. Avoid simple funnel.

### 信息源

Use Signal Tower, Radar Station, Satellite Dish, Observation Deck, Signal Collector, Data Antenna. Avoid ordinary drawer cabinet.

### 内部资产

Use Knowledge Vault, Module Shelf, Asset Archive, Blueprint Wall, Component Library, Knowledge Storage Rack.

### 用户反馈

Use Feedback Radar, Echo Receiver, Signal Return Loop, Voice Collector, Listening Station.

### 内容生产

Use Knowledge Reactor, Content Engine, Idea Workshop, Content Laboratory, Assembly Control Room, Thinking Machine.

### 内容复用

Use Knowledge Crystal, Modular Core, Energy Block, Blueprint Master, Component Splitter, Multipurpose Module Factory. Avoid fish, seafood, cutting board, kitchen metaphor.

### 信任

Use Evidence Architecture, Proof Steps, Trust Foundation, Credibility Pillars, Verification Corridor, Case Display Wall. Avoid generic bridge and handshake cliché.

### 转化

Use Decision Gate, Invitation Door, Action Portal, Conversion Control Room, Final Step Platform, User Arrival Station. Avoid sales funnel cliché.

### 承接

Use Handoff Station, Relay Platform, User Pathway, Content Dock, Successive Rooms, Guided Track System.

### 闭环

Use Orbit System, Feedback Orbit, Circular Rail, Space Station Loop, Energy Return Circuit, System Flywheel. Avoid plain circular arrow.

### 系统承重

Use Bearing Frame, Support Beam, Counterweight System, Crane Structure, Load-bearing Machine, Reinforced Framework.

### 增长

Use Orbit Flywheel, Signal Amplifier, Growth Engine, Compounding Gear System, Expansion Ring. Avoid rocket cliché.

### 内容规划

Use Content Observatory, Star Map, Knowledge Map, Control Wall, Route Planning Table, Mission Board.

### 常见坑

Use Warning Lab, Risk Detector, Trap Map, Broken Circuit Board, Error Inspection Desk, Red Flag Console.

---

## Banned Metaphors

Do not use fish, seafood, cutting board, dead fish, kitchen scene, Xiaohei, black blob, generic funnel, generic bridge, generic well, generic conveyor belt, ordinary flowchart, PPT boxes and arrows, random cute mascot scene.

---

## Preferred Objects

Levers, switches, gauges, signal lights, pipes, modular blocks, blueprints, gears, rails, orbit rings, antennas, radars, control panels, inspection lights, energy cores, crystal modules, evidence pillars, support beams, mechanical arms, observatory windows, knowledge shelves.

---

## Final Principle

A good xuanmu illustration should feel like an intelligent system is being operated by Xuanmu, not like a cute character standing inside a diagram.

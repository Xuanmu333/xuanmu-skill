# xuanmu

中文知识型正文配图生成 Skill  
16:9 白底手绘｜玄木 IP｜蓝黄黑配色｜知识工程隐喻｜Codex Skill

---

## 这个仓库是什么

xuanmu 是一个用于生成中文知识型正文配图的 Codex Skill。

它的核心目标不是“配一张好看的图”，也不是把文字做成 PPT 信息图，而是：

> 把中文文章、方法论、产品思考、内容系统里的一个关键认知动作，转化成一张有记忆点、有逻辑、有美感的手绘解释图。

默认视觉 IP 是「玄木」：一个具有固定蓝黄黑配色、Q 版比例、Builder 气质的角色。玄木不是吉祥物，也不是装饰人物，而是正在操作系统、做判断、搭结构、维护闭环的知识工程师。

一句话：

> xuanmu 让 AI 不只是“画插图”，而是把一个认知系统画出来。

---

## 适合谁用

- 写中文文章，需要正文配图的人
- 做知识型内容、方法论内容、产品思考内容的人
- 想把抽象判断画成具体隐喻的人
- 想形成稳定个人视觉 IP 的内容创作者
- 想让文章插图既有逻辑又有审美的人
- 用 Codex / AI Agent 做内容生产，希望复用一套视觉语言的人

---

## 它会产出什么

默认输出：

- 16:9 横版正文配图
- 白底或暖白底
- 手绘线稿
- 克莱因蓝、那不勒斯黄、黑色为主的控制配色
- 玄木 IP 参与核心动作
- 少量中文手写标注
- 单个清晰认知锚点
- 有系统感、有逻辑、有设计感的视觉隐喻

默认不输出：PPTX、PDF、SVG、HTML、商业海报、封面 KV、大段文字型信息图、完整课程页、严格矢量源文件。

---

## 视觉风格

xuanmu 默认使用「玄木知识工程手绘风」。

核心视觉特征：

- 16:9 横版
- 白底或暖白底
- 手绘线稿
- 少量马克笔质感
- 克莱因蓝作为主视觉色
- 那不勒斯黄作为高亮色
- 黑色作为线条和文字色
- 大量留白
- 主体占画面约 40%-60%
- 一张图只表达一个核心认知动作
- 玄木必须参与核心动作
- 不做普通 PPT 流程图
- 不做儿童卡通
- 不做小黑怪诞风
- 不做鱼、发酵罐、水井、普通桥、普通漏斗等旧隐喻复刻

---

## 玄木 IP

角色特征：

- Q 版比例
- 黑色短发
- 克莱因蓝卫衣
- 那不勒斯黄点缀
- 黑色工装裤
- 黑黄运动鞋
- Builder 气质
- 产品经理 / 知识工程师 / 系统设计者气质

玄木必须操作控制台、调整杠杆、判断信号、建造结构、拆分模块、连接系统、搭建证据、承接反馈、维护闭环或推动内容机器运行。如果去掉玄木，画面的逻辑应该明显不完整。

---

## 核心工作流

1. 读取文章、主题、截图或参考图
2. 识别图中的原始文字
3. 提炼核心认知锚点
4. 判断文字之间的层级、流程和逻辑关系
5. 选择合适的构图模式
6. 从隐喻库中选择或重新发明视觉隐喻
7. 让玄木参与核心动作
8. 生成 16:9 手绘插图
9. 按 QA checklist 检查文字、逻辑、IP、审美和创意
10. 不合格则重新设计，而不是简单重画

---

## 构图模式

- Decision Engine：决策引擎，用于判断、分类、分流、内容策略
- Signal Observatory：信号观测站，用于外部信号、趋势、反馈、信息源
- Knowledge Reactor：知识反应堆，用于内容生产、认知加工、经验沉淀
- Modular Factory：模块工厂，用于内容复用、素材拆解、多用途输出
- Trust Construction Site：信任建设场，用于信任建立、证据积累、长期关系
- Orbit System：轨道系统，用于闭环、反馈、飞轮、增长
- Handoff Architecture：承接结构，用于用户路径、内容路径、钩子品、知识库、核心课
- System Bearing：系统承重，用于自动化、规模化、系统代替人承重
- Content Observatory：内容观测站，用于内容规划、内容地图、知识结构
- Evidence Architecture：证据建筑，用于说服、转化、信任递进

## 禁止复刻的隐喻

禁止默认使用：小黑、黑色实心怪物、鱼、海鲜、切鱼、食材化素材、发酵罐、水井、普通桥、普通漏斗、普通传送带、PPT 箭头流程图、简单盒子连线、儿童卡通贴纸风。

如果用户明确给了参考图，可以参考它的文字、逻辑、层级、流程、认知关系，但不要复刻它的构图、物体、场景、小黑 IP 和旧隐喻。

---

## 文字规则

当用户给出参考图时：

- 不减少原图文字
- 不增加原图没有的文字
- 不替换原图文字
- 不从其他图串入旧文字
- 不自动加标题
- 不自动加英文
- 不添加解释性长句
- 不生成无意义中文
- 不生成错别字严重的文字

如果用户说“不要减少文字，不要增加文字”，则必须严格执行。

```text
Use xuanmu

请根据附件这张图生成一张新图。

要求：
- 使用玄木 IP
- 不要脱离原图文字
- 不要减少原图文字
- 不要增加不在原图里的文字
- 不要复刻原图构图
- 可以脑洞大开
- 要有创意
- 要有美感
- 不要小黑
- 不要鱼
- 配色遵循克莱因蓝、那不勒斯黄、黑色
```

## 安装

克隆或解压本安装包后，将 `xuanmu` 文件夹复制到 Codex skills 目录：

```bash
mkdir -p "${CODEX_HOME:-$HOME/.codex}/skills"
cp -R ./xuanmu "${CODEX_HOME:-$HOME/.codex}/skills/"
```

安装后，在 Codex 中使用：

```text
Use xuanmu
```

## 最终目标

xuanmu 最终要形成一套稳定的个人视觉系统。它不是小黑换脸，也不是 PPT 信息图，也不是可爱角色插画，而是：

```text
玄木 IP + 知识工程 + 系统隐喻 + 中文正文配图
```

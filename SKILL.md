# xuanmu

xuanmu is a Codex Skill for generating Chinese editorial illustrations based on knowledge work, product thinking, content systems, and cognitive structures.

It transforms one abstract idea, judgment, workflow, relationship, or metaphor into a clean, hand-drawn, 16:9 illustration.

The default character is Xuanmu, not Xiaohei.

---

## Core Goal

Do not draw a cute character. Do not copy the reference image. Do not create a PPT flowchart.

Visualize one cognitive action as a memorable system scene.

Each image should explain one idea clearly through:

- Xuanmu IP
- Builder-style visual language
- clear cognitive logic
- creative physical metaphor
- professional hand-drawn aesthetics

---

## Default Output

- 16:9 landscape illustration
- white or warm white background
- hand-drawn linework
- Klein blue, Naples yellow, and black palette
- Xuanmu IP character
- one clear cognitive idea
- short Chinese handwritten labels
- clean negative space
- creative system metaphor

---

## Character

Use Xuanmu IP. See `references/xuanmu-ip.md` and `references/character-consistency.md`. If `assets/character-sheet/character-sheet.png` exists, use it as the visual source of truth for Xuanmu identity.

Xuanmu is a Q-version knowledge builder with black short hair, Klein blue hoodie, Naples yellow accents, black workwear pants, black-yellow sneakers, and Builder mindset.

Xuanmu must actively operate the system. Xuanmu must never be decorative.

Do not generate Xiaohei. Do not generate a black blob character.

---

## Style

Follow `references/style-dna.md`.

xuanmu illustrations should feel clever, structured, professional, handmade, system-oriented, creative, logical, and refined.

Avoid childish cartoon, mascot poster, PPT flowchart, generic boxes and arrows, and visual clutter.

---

## Composition

Follow `references/composition-patterns.md`.

Use patterns such as Decision Engine, Signal Observatory, Knowledge Reactor, Modular Factory, Trust Construction Site, Orbit System, Handoff Architecture, System Bearing, Content Observatory, and Evidence Architecture.

Do not copy the example composition. Use examples only for logic, text, visual density, annotation amount, and style quality.

---

## Metaphor Library

Follow `references/metaphor-library.md`.

Preferred metaphors include control console, knowledge reactor, signal tower, modular factory, evidence architecture, orbit system, system bearing, content observatory, knowledge vault, and decision engine.

Forbidden metaphors: fish, seafood, cutting board, dead fish, Xiaohei, black blob, generic bridge, generic funnel, generic well, generic conveyor belt, PPT flowchart.

---

## Text Rules

If the user provides a reference image, preserve the original text exactly.

- Do not remove original text.
- Do not add new text.
- Do not invent titles.
- Do not carry over text from another image.
- Do not hallucinate Chinese labels.
- Do not translate unless requested.
- Keep text short and handwritten.

If the user says “不要减少文字，不要增加文字”, strictly obey.

---

## Workflow

1. Read the input: article, concept, screenshot, reference image, existing illustration, or user instruction.
2. Identify visible text, core logic, hierarchy, flow direction, required labels, and forbidden changes.
3. Extract the single most important cognitive anchor.
4. Select a composition pattern from `references/composition-patterns.md`.
5. Reinvent the physical metaphor using `references/metaphor-library.md`.
6. Place Xuanmu in the core action: operate, control, build, connect, judge, sort, inspect, maintain, or adjust.
7. Generate the image with 16:9 landscape, white background, hand-drawn linework, blue-yellow-black palette, clean negative space, professional editorial style.
8. QA check using `references/qa-checklist.md`.

Reject and regenerate if text is missing, extra text appears, Xiaohei appears, fish appears, visual logic is wrong, composition is copied, Xuanmu is decorative, or the image lacks design quality.

---

## Reference Image Redesign Rule

Use the reference image for text, logic, relationships, hierarchy, and flow.

Do not use it for exact composition, exact object, exact scene, old IP, or old metaphor.

Successful redesign = same logic, same words, new metaphor, new IP, better design.

---

## Final Quality Bar

A final image should pass these tests:

1. Does it preserve the original text?
2. Does it preserve the original logic?
3. Is Xuanmu correctly represented?
4. Is Xuanmu doing the core action?
5. Is the metaphor new?
6. Is the design beautiful?
7. Is it clearly not Xiaohei style?
8. Is it clearly not a PPT flowchart?
9. Would this image be usable in a professional article?
